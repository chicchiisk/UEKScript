# KScript サンプルスクリプト

Phase3で実装されたセーブ/ロード機能とトランジション機能をテストするためのサンプルスクリプトです。

## ファイル一覧

### 1. phase3_test.ks
**Phase3の全機能を網羅的にテストするスクリプト**

- **テスト内容:**
  - 基本的なトランジション（フェード、スライド）
  - 変数の設定とセーブ機能
  - ロード機能（変数の復元確認）
  - 複数のトランジション効果
  - 条件分岐とセーブ/ロードの組み合わせ
  - マルチメディア（BGM、SE）との統合
  - サブルーチンとの連携

- **使用コマンド:**
  - `[save slot="スロット名"]` - ゲーム状態の保存
  - `[load slot="スロット名"]` - セーブデータのロード
  - `[trans method="種類" time="時間"]` - トランジション設定

### 2. simple_save_test.ks
**セーブ/ロード機能のシンプルなテスト**

### 3. transition_test.ks
**トランジションエフェクトの詳細テスト**

詳細は各スクリプトファイルのコメントを参照してください。

## Phase3で追加された機能

### 新規コマンド
- `[save]` - セーブ機能
- `[load]` - ロード機能
- `[trans]` - トランジション設定

### 新規クラス
- `UKScriptSaveGame` - セーブデータ管理
- `UKScriptTransitionManager` - トランジション管理

## 実行方法

UE5エディタでKScriptサブシステムを使用してスクリプトをロードし、実行してください。
