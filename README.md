# UEKScript

**ティラノスクリプト風スクリプト言語をUnreal Engine 5で実装するプロジェクト**

## プロジェクト概要

UEKScriptは、日本で人気の高いノベルゲーム制作エンジン「ティラノスクリプト」風のスクリプト文法をUnreal Engine 5上で動作するように実装したスクリプトエンジンです。

### 目標
- ティラノスクリプトのタグベーススクリプト文法の実装
- UE5の強力な3D機能とビジュアル表現を活用したノベルゲーム制作環境の提供

## プロジェクト構成

```
UEKScript/
├── Source/                      # 開発・テスト用プロジェクト（サンプルのみ）
│   ├── UEKScript/              # サンプルゲームモジュール
│   ├── UEKScriptEditor.Target.cs
│   └── UEKScript.Target.cs
├── Plugins/                     # プラグイン（メイン開発場所）
│   └── KScript/                # KScript プラグイン（全機能をここに実装）
│       ├── Source/             # プラグインのC++ソースコード
│       │   ├── KScript/        # ランタイムモジュール
│       │   └── KScriptEditor/  # エディタ拡張モジュール
│       ├── Content/            # プラグイン用アセット
│       ├── Resources/          # アイコン等のリソース
│       └── KScript.uplugin     # プラグイン定義ファイル
├── Content/                     # サンプルゲーム用コンテンツ
└── Config/                      # プロジェクト設定ファイル
```

### 重要な開発方針

**🚨 すべてのKScriptエンジン機能は`Plugins/KScript`以下に実装してください 🚨**

- **ルートプロジェクト（`Source/UEKScript`）**: サンプルゲームとテスト用途のみ
- **プラグイン（`Plugins/KScript`）**: 全てのエンジン機能を実装
- **配布時**: `Plugins/KScript`フォルダのみを他のプロジェクトにコピーして使用

この構成により、プラグインとして簡単に配布・導入が可能になります。

## 主要機能

### 基本スクリプト機能

- **テキスト表示系**
  - `[l]` - クリック待ち
  - `[p]` - クリック待ち＋改ページ
  - `[r]` - 改行
  - `[cm]` - メッセージクリア

- **制御構文**
  - `[if][else][endif]` - 条件分岐
  - `[jump]` - シナリオジャンプ
  - `[call][return]` - サブルーチン

- **変数操作**
  - `[eval]` - 式の評価
  - `[emb]` - 変数の埋め込み

- **マルチメディア**
  - `[bg]` - 背景変更
  - `[chara_show][chara_hide]` - キャラクター表示
  - `[playbgm][playse]` - 音声再生

### UE5拡張機能

- ブループリントとの連携
- UE5のマテリアルシステム活用
- 3D空間での演出
- 物理エンジンとの統合

### クラス設計指針

**プラグイン内でのクラス配置**

すべてのKScriptエンジン機能は`Plugins/KScript/Source/KScript/`以下に実装します：

```cpp
// プラグイン内の主要クラス構成例
// Plugins/KScript/Source/KScript/Public/ (Runtime)
class KSCRIPT_API UKScriptEngine : public UObject
{
    // スクリプト実行エンジン
};

class KSCRIPT_API UKScriptParser : public UObject
{
    // スクリプト解析器
};

class KSCRIPT_API UKScriptVariable : public UObject
{
    // 変数管理
};

class KSCRIPT_API UKScriptSubsystem : public UGameInstanceSubsystem
{
    // ゲーム全体でのKScript管理
};

// Plugins/KScript/Source/KScriptEditor/Public/ (Editor Only)
class KSCRIPTEDITOR_API FKScriptEditorModule : public IModuleInterface
{
    // エディタモジュールのメインクラス
};

class KSCRIPTEDITOR_API UKScriptAssetFactory : public UFactory
{
    // .ksファイルの作成・インポート支援
};
```

### モジュール分離

- **KScript（Runtime）**: ゲーム実行時に必要な機能
- **KScriptEditor（Editor Only）**: エディタ拡張機能
  - スクリプトファイル（.ks）のシンタックスハイライト
  - エディタ内でのスクリプト編集支援
  - デバッグツールとプレビュー機能
  - アセット管理とプロジェクト統合
- **サンプルプロジェクト**: 使用例とテストケース

### ファイル構成規則

- **スクリプトファイル**: `.ks`拡張子
- **設定ファイル**: JSON形式
- **リソース管理**: UE5のアセット参照システム使用

### コーディング規約

#### ログ出力
- **ログカテゴリ**: `LogKScript`を使用してください（`LogTemp`は使用禁止）
- **ログメッセージ**: 日本語で記述してください
- **使用例**:
  ```cpp
  // 正しい例
  UE_LOG(LogKScript, Log, TEXT("スクリプトの読み込みに成功しました"));
  UE_LOG(LogKScript, Error, TEXT("パーサーが初期化されていません"));
  
  // 誤った例（使用禁止）
  UE_LOG(LogTemp, Log, TEXT("Script loaded"));  // LogTempと英語は使わない
  ```

- **パフォーマンス**: UE5のガベージコレクションを考慮したメモリ管理

- **エディタ統合**: UE5エディタでのスクリプト編集支援機能

## 貢献方法

### 開発時の注意事項

1. **プラグイン優先開発**: すべての機能は`Plugins/KScript`以下に実装
2. **ルートプロジェクトの用途**: サンプル・テスト・デモンストレーションのみ
3. **API設計**: 他のUE5プロジェクトから簡単に使用できるインターフェース設計

### 貢献手順

1. Issue報告
2. Pull Requestによる機能追加・修正
3. ドキュメントの改善
4. テストケースの追加（サンプルプロジェクトで実装）

### プラグイン配布準備

配布時は以下の手順でプラグインを抽出：
1. `Plugins/KScript`フォルダをコピー
2. 必要に応じてドキュメントを添付
3. 他のUE5プロジェクトの`Plugins`フォルダに配置してテスト
